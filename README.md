# CAW Names — QL1

A read-only directory of every CAW name minted on QL1, read directly from the
CawName contract (`0x864f08Af11F6DC2c0De42562e4664d4f033D393f`, QL1 chain id 766)
in the visitor's browser at load time — no server, no stored list.

- Order: names starting with a digit first, then alphabetical
- Search: substring match
- Length filter: 1–7 characters individually, 8+ grouped
- Each row shows the name's ERC-721 owner

Site: https://ql1-infinite42-guppy-histoire.github.io/ql1-caw-names/
